# Contributing

Build in your own lab. Use synthetic data in examples and reports. Keep changes
small, explain the reason, and record expected and actual test results. Do not
copy college assessment answers into this repository or present this pack as
independent assessed work. Follow your course's disclosure and attribution rules.

Before a pull request, run `python3 -m unittest discover -s tests -v`, review
`git diff --cached`, and follow docs/12-sharing.md. Never attach real .env files,
databases, recovery codes, API responses or full diagnostic archives.

Third-party components have their own licenses. Do not add copyrighted media,
proprietary assets, credentials, access-bypass material or software you have no
permission to redistribute. A privacy tool or a media server is not inherently
illegal; keep any example use lawful and authorised.
